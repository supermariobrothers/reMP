# reMP

SA-MP 0.2.5 client continuation and compatibility fixes for 0.3.7 servers.

## Features
- SA-MP 0.3.7 server handshake and RPC support
- Class selection and spawn handling fixes
- Ped model validation and skin fallback
- Audio and streaming crash fixes
- Built-in color embedding support

## Building
- Visual Studio 2005 / 2008
- DirectX 9 SDK (Summer 2004)
- RakNet 2.x

Open samp.sln and build client in Release mode.
